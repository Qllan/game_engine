# RTS Engine - Итерация 1: Архитектурное Ядро

## 📋 Обзор

Это первая итерация масштабируемого 2D RTS-движка на Python. Фокус на **чистой архитектуре** и **модульности**, а не на графике.

## 🏗️ Архитектурные Решения

### 1. **ECS (Entity-Component-System)**
- **Entity** - просто контейнер для компонентов (без логики)
- **Component** - чистые данные (позиция, скорость, рендер)
- **System** - логика обработки (движение, рендеринг, выделение)

**Преимущества:**
- Гибкая композиция объектов
- Легко добавлять новые типы юнитов
- Подходит для будущих оптимизаций (кэширование, пулы объектов)

### 2. **Event Bus**
- Слабая связность между системами
- События: `UnitCreated`, `UnitMoved`, `GameTick`
- Критично для будущей сетевой архитектуры

### 3. **Data-Driven Design**
- Данные юнитов загружаются из JSON файлов
- Можно балансировать игру без изменения кода
- Подготовка для модов

### 4. **Слои Архитектуры**
```
rts_engine/
├── core/          # Ядро (Event Bus)
├── ecs/           # ECS система
│   ├── core.py    # Компоненты и Сущности
│   └── systems.py # Системы обработки
├── data/          # Работа с данными
│   └── manager.py # Загрузка JSON конфигов
├── data/          # JSON файлы с данными
└── main.py        # Игровой цикл
```

## 🚀 Запуск

```bash
cd rts_engine
python main.py
```

## 📊 Что Работает в Этой Итерации

✅ **ECS Система:**
- Создание сущностей с компонентами
- Query системы для выборки сущностей по компонентам

✅ **Компоненты:**
- `PositionComponent` - позиция в 2D
- `VelocityComponent` - скорость
- `RenderComponent` - цвет, форма, размер
- `SelectionComponent` - выделение
- `UnitComponent` - тип юнита, здоровье

✅ **Системы:**
- `MovementSystem` - движение юнитов
- `RenderSystem` - сбор данных для отрисовки
- `SelectionSystem` - выделение (по клику и области)

✅ **Data Layer:**
- Загрузка конфигураций из JSON
- Кэширование данных
- Горячая перезагрузка (clear_cache)

✅ **Event Bus:**
- Подписка/отписка на события
- Публикация событий
- Предопределенные типы событий RTS

## 🎮 Демо Сценарий

В `main.py` демонстрируется:
1. Создание 3 типов юнитов из JSON конфига
2. Задание скорости рабочему
3. Выделение конкретного юнита
4. 3 игровых тика с движением
5. Выделение по области

## 🛠️ Расширение

### Добавить новый тип юнита:
1. Отредактируйте `data/units.json`
2. Добавьте новые параметры в конфиг
3. Юнит автоматически доступен в игре

### Добавить новый компонент:
```python
@dataclass
class HealthComponent(Component):
    current_health: int = 100
    max_health: int = 100
```

### Добавить новую систему:
```python
class CombatSystem(BaseSystem):
    def update(self, delta_time: float):
        # Логика боя
        pass
```
